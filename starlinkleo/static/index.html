    Mesure la latence au repos, puis pendant un download et un upload saturés. L'écart = bufferbloat. Le test consomme ~300-500 Mo de données.

    Autres leviers
    
      
      
        
    • Mode bypass : passez le routeur Starlink en bypass pour que le routeur OpenWrt gère seul la file d'attente.
      • 
        
    • Accès à la parabole en bypass : ajoutez une IP 192.168.100.2/24 sur le WAN OpenWrt pour garder l'accès à 192.168.100.1.
      • 
        
    • Lien filaire 1 Gb/s entre parabole et routeur (alerte « Ethernet lent » à surveiller).
      • 
        
    • Wi-Fi : le bufferbloat peut aussi venir du Wi-Fi ; testez en filaire pour isoler.
      • 
        
    • Panneau LuCI complet : openwrt-starlink-control.
